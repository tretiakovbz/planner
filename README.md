# Цели и сроки

Telegram Mini App: планер целей с обратным отсчётом и спокойными напоминаниями от бота.

Весь сервис живёт в одном файле `index.tsx` (Bun): страница планера, API целей, вебхук бота и рассылка напоминаний. Данные хранятся в SQLite на томе `/data`.

## Переменные окружения

- `BOT_TOKEN` — токен бота от @BotFather. Без него сервис запускается, но бот и вход в планер не работают.
- `SEED_JSON` — необязательный стартовый список целей (массив `{title, deadline, cat, step}`). Добавляется один раз первому пользователю.
- `RAILWAY_PUBLIC_DOMAIN`, `RAILWAY_VOLUME_MOUNT_PATH`, `PORT` — выставляет Railway.

## Как это работает

- При старте сервис сам ставит вебхук, кнопку «Планер» в чате и команды бота.
- Планер проверяет подпись Telegram, поэтому каждый видит только свои цели.
- Отдельный cron-сервис `reminders` раз в час дёргает `/tick`; сервис решает, кому пора написать.

## Локальный запуск

```
BOT_TOKEN=... DATA_DIR=./d PORT=3000 bun index.tsx
```
